# Daily Expense Tracker

This is a simple Python project for keeping track of daily expenses.

## Features

* Add a new expense
* Show all expenses
* Calculate total expenses
* Calculate average expense
* Search expenses by category
* Exit the program

## Technologies Used

* Python
* Lists
* Functions
* Loops
* If-Else statements

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python expense_tracker.py
```

## Categories

You can add expenses such as:

* Food
* Travel
* Bills
* Other
